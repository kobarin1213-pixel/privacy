Privacy Policy

This is a personal tool used only by its developer. It is not offered to anyone else.

With the user's permission, it reads YouTube Analytics data (read-only) for the user's own channel and saves it to a file on the user's own computer.

  • The data is not sent to, shared with, or sold to any third party.
  • No data is stored on any server.
  • Access can be revoked at any time from Google Account permissions.
